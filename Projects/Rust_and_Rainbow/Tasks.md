- [x] **Background-removal bug found + fixed for 10 live designs — 2026-07-04.** rembg was silently leaving solid black regions of flat/typographic designs at near-zero alpha (measured: 0.2% of black text pixels fully opaque, mean alpha 35/255 on "Velcro Dog Typography") — printed as a faint gray ghost on colored garments instead of solid black. Root-caused via pixel-level alpha analysis, not just visual inspection. Tried `rembg(alpha_matting=True)` as a same-day fix — made it WORSE (7.1% opaque). Adobe's Photoshop "remove background" API (via the Adobe Creativity connector, called interactively from a Claude session) does not have this bug (96.4% opaque on the same test image) and costs **$0 of the 250 monthly Firefly credits** (confirmed against Adobe's own docs — background removal is a non-generative masking feature, unlimited on standard plans, separate from the generative-credit pool). Reprocessed all 10 affected designs' original source images through Adobe's API (programmatic upload via `asset_initialize_file_upload`/`asset_finalize_file_upload`, no manual file-picker needed since Claude has direct filesystem access on this Mac), replaced the buggy rembg outputs in `output/` (old ones backed up to `output/rembg_backup/`), then deleted and republished all 34 affected Printify/Etsy products via a new script `redo_bg_designs.py` (reuses `agent.py`'s own `remove_listing`/`_upload_design_image`/`_create_and_publish_product` — same code path as a normal run). All 34 new products confirmed live (`visible: true`) via Printify API. **Verified zero sales existed on any of the 10 designs before deleting** (agent's own `sales` field, cross-checked against Printify product data — Etsy's own receipts API is unreachable, see the permanent app ban below, so this could not be independently confirmed via Etsy directly; Ryan confirmed proceeding was fine). Documented the automation limitation directly in `agent.py`'s `_remove_background()` docstring: Adobe's tool only works in an interactive Claude session (Ryan's Adobe login via the Creativity connector), NOT from this unattended cron script — there are no `ADOBE_*` API credentials in `.env`, and getting them would need a separate (likely paid, enterprise-tier) Firefly Services Developer Console app, distinct from the personal 250-credit consumer plan. So rembg remains the automated default for new weekly designs; any that show the ghosting artifact need a manual interactive Adobe reprocess pass (pattern is now in `redo_bg_designs.py`). **Still open:** Instagram delete+repost for 4 of these designs (Velcro Dog Line Art, Rainbow Vizsla Silhouette, Vizsla Puppy Sticker, Pride Flag Vizsla — known IG post IDs from `market.log`) is blocked on the broken `META_ACCESS_TOKEN` above.
